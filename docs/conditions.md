ne sont pas remplacés par une licence de ce dépôt.

des données tierces. Le nom de paquet `open-sauce`, les informations d'auteur et le
squelette initial ont été conservés. `ossgeo` est la commande du projet ; `open-sauce`
est conservée comme alias de cette commande.
