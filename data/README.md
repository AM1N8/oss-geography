# Données du projet

`raw/` conserve les originaux ; `processed/` reçoit les tables préparées ; `metadata/`
contient les petits manifestes reproductibles et rapports de qualité. Les données brutes
et préparées sont exclues des commits ordinaires par `.gitignore`. Conserver et échanger
les instantanés complets avec leurs manifestes : voir `docs/reproduction.md`.
